# Helix Aegis

Full-colour Python 3 neon rotating-shield arcade for [ElbowOS](https://x.com/ElbowOS).

Spin a gold helix around an amber core and intercept incoming colour shards. Left / Right (or A / D) rotate the shield. Combos stack. Three aegis lives.

## Play

```bash
pip install -r requirements.txt
python3 helix_aegis.py --play
```

## Record a 9:16 reel

```bash
python3 helix_aegis.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
